# 🎬 Movies App

A modern **Movie App** built with **Flutter & Dart**, designed to provide users with a smooth and simple experience for discovering and exploring movies.

The application uses a **REST API** to retrieve movie data and **Hive** for local data storage, providing a combination of dynamic content and efficient local persistence.

## 🚀 Getting Started

### Prerequisites

Make sure you have the following installed:

* Flutter SDK
* Dart SDK
* Android Studio or VS Code
* An Android Emulator or physical device

### Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd movies
```

3. Get the project dependencies:

```bash
flutter pub get
```

4. Run the application:

```bash
flutter run
```

---

## 🔑 API Configuration

This application uses a REST API to retrieve movie information.

If an API key is required, add your API key to the appropriate configuration file before running the application.

> **Note:** Never upload private API keys or sensitive credentials to GitHub.

---

## 💾 Local Storage

**Hive** is used in this project for local data persistence.

It allows the application to store data locally and access it efficiently without requiring a network request every time.
